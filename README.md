# mapa.covepolska.pl

Statyczna mapa szkolnictwa sektorowego we Wrocławiu.

Mapa pozwala przeglądać branże, profile, typy ścieżek kształcenia oraz szkoły prowadzące wybrane zawody.

Adres docelowy:

```text
https://mapa.covepolska.pl
```

Repozytorium jest przygotowane pod GitHub Pages. Plik `CNAME` ustawia domenę niestandardową.
